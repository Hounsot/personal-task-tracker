# Focus — личный трекер задач

Адаптивный MVP на React, TypeScript и Vite. Задачи и аккаунты хранятся в Supabase; опубликованная версия доступна через GitHub Pages.

## Ветки

- `main` — стабильная опубликованная версия.
- `codex/dark-mode` — отдельная ветка с тёмной темой, пока не включённая в `main`.

Новые изменения создаём в отдельных ветках и объединяем с `main` после проверки.

## Запуск

```bash
npm install
npm run dev
```

## Что работает

- Splash, список задач, просмотр деталей и форма новой задачи.
- Создание задачи с проверкой названия.
- Открытие, закрытие и удаление задачи.
- Адаптация для мобильного экрана и компьютера.

Подробные архитектурные решения описаны в `architecture.md`.
